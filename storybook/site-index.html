SYX — un sistema, tres frameworks

Los 27 componentes de SYX renderizados por tres runtimes distintos desde una única fuente: component-registry.json. Los wrappers de React y Vue están generados, no escritos — cero excepciones manuales — y un pixel-diff automático comprueba que los tres catálogos pintan idéntico.

  • HTMLLa línea base: el markup del registro, verbatim. CSS puro.
  • ReactWrappers JSX generados: props tipadas desde los modifiers.
  • Vue 3Los mismos wrappers como render functions de Vue.
